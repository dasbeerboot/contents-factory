# 이미지 규칙

## 목적

이 문서는 상품컷, 카드뉴스, 썸네일, 리뷰컷, OG 이미지처럼 생성형 이미지가 들어가는 작업의 공통 규칙이다.

목표는 크레딧 낭비를 줄이고, 제품 구조와 인물 정체성을 보존하며, 최종 채택 전에 원본 크기 검수를 통과시키는 것이다.

## 절차

1. 작업 전에 이미지의 목적, 플랫폼, 비율, 필수 피사체, 금지 피사체, 최종 사용 위치를 확정한다.
2. 레퍼런스 우선순위를 정한다. 정확한 제품/인물 레퍼런스, 구조 디테일, 장면 무드, 색감 순서로 둔다.
3. 제품이나 물체 구조는 공급사 상세 이미지, 실측 이미지, 사용자가 준 기준 이미지를 먼저 보고 문장화한다. 추측으로 쓰지 않는다.
4. 애매한 지시가 있으면 전량 생성 전에 샘플 1장을 만든다. 크롭, 톤, 로고, 위치, 배경 해석은 샘플 확인 뒤 확장한다.
5. 기본 배치는 `파일럿 3장 → 확인 → 전량` 순서로 간다. 확인 없이 10장 이상 전량 생성하지 않는다.
6. 레퍼런스는 한 번에 3장 이하로 제한하고, 서로 다른 목적의 레퍼런스는 단계로 나눈다.
7. 인물 또는 장면 생성과 제품 삽입은 분리한다. 먼저 장면을 잡고, 제품은 로컬 편집 단계에서 교체한다.
8. 로컬 편집 프롬프트는 바꿀 대상을 좁힌다. 대상 외의 얼굴, 피부, 자세, 배경, 조명, 질감은 유지하라고 명시한다.
9. 부정 지시로 반복 실패하는 요소는 구도로 막는다. 손에 들면 안 되는 물체는 손이 물체 근처에 없는 구도를 고른다.
10. 캡션, 가격, 카피, 사이즈, 안내 문구는 이미지 안에 넣지 않고 HTML, 캔버스, 디자인 레이어에서 올린다.
11. 생성 결과에는 버전 접미사를 붙인다. 채택본만 정식 이름으로 복사하고, 폐기본은 날짜별 보관소에 남긴다.
12. 최종 채택 전에는 원본 크기로 1장씩 검수한다. 썸네일 시트는 선별용일 뿐 승인 근거가 아니다.

## 게이트(PASS·FAIL 기준)

PASS:

- 원본 크기로 파일별 검수를 했다.
- 주요 피사체의 실루엣, 구조, 포켓, 핸들, 버튼, 소재, 로고 위치가 기준 이미지와 맞다.
- 인물 이미지라면 얼굴, 피부 질감, 나이 인상, 헤어, 체형이 기준과 일관된다.
- 삽입 물체가 정확한 개수와 위치에 있고 손, 옷, 배경과 물리적으로 충돌하지 않는다.
- 배경 구조물이 상식적이다. 벤치, 계단, 창, 선반, 문틀, 타일, 그림자 방향이 깨지지 않는다.
- 텍스트, 워터마크, 읽히는 타사 로고, 가짜 캡션이 없다.
- 상단과 하단 스트립에 의도치 않은 글자 조각이나 UI 잔재가 없다.
- 비율과 크롭이 플랫폼 규격에 맞고, 얼굴이나 제품 핵심부가 잘리지 않는다.
- 리뷰컷이나 UGC 컷은 과하게 완성된 광고컷처럼 보이지 않는다.
- 폐기본과 채택본이 원장과 대조 가능하게 남아 있다.

FAIL:

- 썸네일 시트만 보고 승인했다.
- 제품 구조를 추측으로 썼다.
- 레퍼런스가 섞여 다른 제품, 다른 얼굴, 다른 배경이 나왔다.
- 이미지 안에 카피, 가격, 사이즈표, 워터마크가 들어갔다.
- 손가락, 팔, 신발, 가방끈, 소품 위치가 물리적으로 어색하다.
- 반복 패턴 배경이 휘거나 끊어졌다.
- 로컬 편집이 대상 외 얼굴, 피부, 배경, 조명을 바꿨다.
- 실패 원인을 프롬프트 문장만 더해 해결하려고 같은 배치를 반복했다.

필수 원본 크기 검수 크롭:

- 핵심 제품 또는 물체 영역.
- 얼굴 또는 정체성 기준 영역.
- 삽입 소품 영역.
- 상단과 하단 텍스트 스트립.
- 배경 구조물 영역.

## 금지

- 확인 없이 전량 배치 생성.
- "대충", "담백하게", "반쯤"처럼 해석이 갈리는 지시를 임의로 확정.
- 공급사 구조나 실제 제품 비율을 상상으로 보완.
- 4장 이상 레퍼런스를 한 번에 넣어 섞이게 만들기.
- 이미지 안에 본문 카피, 가격, 안내 문구를 굽기.
- 얼굴 리파인 편집으로 정체성까지 재렌더하기.
- 폐기본 삭제. 원장 대조와 재발 방지를 위해 보관한다.
- 최종 채택 전에 원본 크기 검수를 생략하기.

## 예시

좋은 진행:

- "제품 구조 스크린샷을 먼저 문장화한다."
- "장면 3장만 파일럿으로 뽑고, 승인 뒤 색상 변형을 확장한다."
- "가방만 교체하고 얼굴, 피부, 옷, 배경, 조명은 유지한다."

나쁜 진행:

- "상세 이미지를 보지 않고 일반 가방 구조로 쓴다."
- "문구는 이미지 안에 넣고 나중에 고친다."
- "10장 썸네일에서 괜찮아 보이니 바로 채택한다."

검수 예시:

- PASS: 제품은 1개, 손에 들려 있지 않고, 구조와 색이 기준 이미지와 같으며, 배경 선이 자연스럽다.
- FAIL: 제품은 맞지만 얼굴이 다른 사람처럼 바뀌었거나, 배경 벤치가 끊어져 있다.
