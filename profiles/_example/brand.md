# Brand

## Reference priority

1. Approved asset in `assets/approved/` wins over anything generated.
2. Generated variant from a locked prompt in the brief.
3. Fresh generation. Only when neither of the above exists.

## Marks

- Logo: `assets/approved/logo.svg`. Never redraw, never recolor, never add effects.
- Clear space around the mark is at least the height of the mark's cap.

## Colour

- Ink `#14161A`, paper `#FAFAF7`, accent `#2F6F4E`.
- One accent per image. Accent is for a single element, not for backgrounds.

## Type

- Headline: Inter Tight, 600. Body: Inter, 400.
- Sentence case everywhere. No all caps.

## Imagery

- Real surfaces, real light, visible texture. No glossy 3D renders, no gradient meshes.
- Text inside an image: at most one short line, inside the caption safe zone.
